# References

Every outside source we lean on, in one place. Before writing a new gag, bridge or effect, come
back here first; add to it whenever something new is used.

## Motion style

- [docs/style-reference.md](style-reference.md): the "one shape, never cut" UI motion studies by
  @twoclipping on X (https://x.com/twoclipping/status/2103273003555402193 and
  https://x.com/twoclipping/status/2109300899227095264). Validated look: Apple / Dribbble, liquid
  glass, closed-form springs, motion blur.

  - Harmonic, server-side double-box and L-bar ads: https://harmonicinc.com/insights/blog/in-stream-ads-vos-ad
