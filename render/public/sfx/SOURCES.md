# Sound effects

Recorded UI sounds, no music.

- `mixkit-*.mp3`: Mixkit sound effects (Mixkit Free License, free for commercial use), https://mixkit.co/free-sound-effects/
- `kenney-*.ogg`: Kenney UI Audio pack (CC0), https://kenney.nl/assets/ui-audio

The Mixkit files are not committed (their license does not allow redistributing the files themselves). Download them from mixkit.co: 2577 (pop), 166 (whoosh), 3115 (swipe), 1396 (tick), saved as `mixkit-<id>.mp3`.
